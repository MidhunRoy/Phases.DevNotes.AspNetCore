How to annotate code

Add short learning notes in your source files, then scan so they appear in Code Guide.

1. Write a DEVNOTE in code

// DEVNOTE: WebApplicationBuilder
// What: Creates a builder used to prepare an ASP.NET Core application.
// Why: It sets up configuration, logging and services.
// Why here: We use the builder to configure the application.
// Example: `var builder = WebApplication.CreateBuilder(args);`
  • First line after DEVNOTE: becomes the title.
  • Structured lines (What:, Why:, Why here:, Advantage:, How:, Example:) become learning sections. All fields are optional.
  • File path and line number are captured automatically.

2. Scan the project

Click Scan Project, select the DEVNOTE results, then Import Selected.

3. Browse in Code Guide

Open the Code Guide tab. Annotations are grouped by file and sorted by line number. Search for concepts like middleware or dependency.

Also supported

/*
 DEVNOTE: Middleware
 What: Code that runs while an HTTP request travels through the application.
 Why: Common request processing can be handled in one place.
 Example: Request → Middleware → Endpoint → Response
*/

Work notes still use TODO, FIXME, BUG, IDEA, etc. Those stay in Notes. Use DEVNOTE for learning annotations.
